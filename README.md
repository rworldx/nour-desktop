# Nour for Mac and Windows

This repository only holds the installers for Nour, the study buddy from [StudyNest](https://studynest.dev). It contains no source code.

Download and install steps: **https://studynest.dev/download**

- Mac (Apple silicon): `Nour-mac-apple-silicon.dmg`
- Mac (Intel): `Nour-mac-intel.dmg`
- Windows: `Nour-windows.exe`

Questions: https://studynest.dev/support
